## Версионирование и сборка

Источник истины переехал из Overleaf в этот git-репозиторий (`git init` 21.08.2026). Причина — у Overleaf на бесплатном плане нет программного доступа: история версий ограничена последними 24 часами, git-мост доступен только на премиуме, а read-only ссылка отдаёт SPA-оболочку (проверено 21.08.2026). Автоматизировать можно лишь то, к чему есть доступ.

- Движок — Typst 0.15.1, поставлен через `winget install Typst.Typst`, бинарь `~/AppData/Local/Microsoft/WinGet/Links/typst.exe`.
- Сборка: `typst compile cv/cv.typ out/cv.pdf`; PDF в историю не коммитится (см. `.gitignore`), собирается из тега.
- Версия = тег `cv-ГГГГ-ММ-ДД` на коммите, с которого отправляли резюме. Вариант под конкретную вакансию — отдельный файл в `cv/`, а не ветка: варианты живут параллельно, а не сменяют друг друга.

## Автосбор

Раз в период (n8n-cron, не `CronCreate` — задания сессии умирают вместе с ней) и по кнопке действия проекта в платформе:

1. `log_digest.py` из скилла `karim.history` собирает промпты за период с последней метки.
2. Профессиональное отбирается и формулируется по XYZ из регламента; работа без числа не выбрасывается, а попадает строкой в реестр ожидаемых результатов (`pending-results.md` в папке задачи в Obsidian-vault) с датой пинга.
3. Просроченные пинги превращаются в напоминание «собери результаты по X».
4. Пополнение стопки идёт автоматически, правка самого CV — только с подтверждения: из логов виден процесс, а не результат.

## Старое CV в Overleaf

Действующее резюме собрано в Overleaf на LaTeX, ссылка на чтение — в таблице выше. По read-only ссылке содержимое программно не читается: Overleaf отдаёт SPA-оболочку, в ответе только заголовок «Overleaf, Online LaTeX Editor» (проверено 21.08.2026). Чтобы работать с текстом резюме здесь, нужен исходник — экспорт `.tex`/PDF в эту папку либо доступ к проекту Overleaf на запись.

Отсюда следствие для работы: пока исходника нет, сверить содержимое CV с резюме-стопкой (что уже вошло, каких метрик не хватает) можно только глазами Карима, не инструментом.
